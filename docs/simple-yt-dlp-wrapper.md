# Python製簡易GUIダウンローダ 完成版仕様書

## 1. 概要

本アプリは `yt-dlp` と `ffmpeg` をバックエンドとして利用する、`PyQt6` 製の簡易 GUI ダウンローダである。ユーザーが動画 URL を入力して分析し、取得可能なメタデータとフォーマット情報を確認したうえで、指定したモードで動画・音声・字幕をダウンロードできることを目的とする。

対象 OS は Windows を優先とする。

## 2. 目的

- 動画 URL を GUI で簡単に分析できること
- ダウンロード可能な動画・音声・字幕情報を可視化できること
- ワンクリックの高品質ダウンロードと、手動選択ダウンロードの両方に対応すること
- 前回設定を復元し、継続利用しやすいこと

## 3. 用語定義

### 3.1 対応URL

`yt-dlp` が対象 URL に対して情報取得および実際のダウンロード処理を行える場合、その URL を「対応URL」と定義する。

以下の場合は「非対応URL または 取得失敗」とみなす。

- `yt-dlp` による情報取得に失敗した場合
- 情報取得はできても、選択可能な実ダウンロード対象が存在しない場合
- DRM などにより通常のダウンロード処理が成立しない場合

### 3.2 動画フォーマット

映像を含むフォーマット、または映像専用フォーマットを指す。

### 3.3 音声フォーマット

音声を含むフォーマット、または音声専用フォーマットを指す。

### 3.4 字幕

`yt-dlp` が取得可能と判断した字幕情報を指す。通常字幕と自動生成字幕を含む場合がある。

## 4. 技術要件

- GUI フレームワークは `PyQt6` を使用する
- ダウンロード処理および情報取得は `yt-dlp` を使用する
- マージ処理は `ffmpeg` を使用する
- サムネイル取得は `yt-dlp --list-thumbnails`経由で行う
- 設定保存はローカル設定ファイルで行う
- 対応 OS は Windows を優先対象とする
- 字幕ダウンロード優先言語は日本語とする
- `yt-dlp` と `ffmpeg` は次のいずれでも利用可能とする
  - `PATH` に存在する
  - アプリ実行ファイルと同じディレクトリに存在する

## 5. 外部依存の確認

### 5.1 起動時確認

アプリ起動時に `yt-dlp` および `ffmpeg` の利用可否を確認する。

### 5.2 起動時確認失敗時の挙動

- `yt-dlp` が見つからない場合は警告を表示する
- `ffmpeg` が見つからない場合は警告を表示する
- 不足している依存がある場合でもアプリは起動してよい
- ただし、該当機能の実行時に再度エラー表示を行う

### 5.3 機能制限

- `yt-dlp` が見つからない場合、URL分析およびダウンロード開始は不可とする
- `ffmpeg` が見つからない場合、マージが必要なフォーマットのダウンロードは不可とする

## 8. URL分析機能

### 8.1 入力

- ユーザーは URL 入力欄に 1 件の URL を入力する
- ペーストボタン押下でクリップボードから自動貼り付けする
- `URL分析` ボタン押下で分析を開始する

### 8.2 分析処理

- URL が空の場合は分析を行わずエラーメッセージを表示する
- `yt-dlp` を用いて情報取得を試行する
- URL分析の中止は許可しない
- 分析処理は UI をブロックしない方法で実行する
- `yt-dlp --simulate`で `yt-dlp` のダウンロード可否を判断
- `yt-dlp --format FORMAT`や`yt-dlp --format-sort SORTORDER`でビデオフォーマット確認

### 8.3 成功条件

以下をすべて満たした場合、分析成功とする。

- メタデータ取得に成功している
- 少なくとも 1 つ以上の実用的なダウンロード候補が存在する

### 8.4 成功時の表示

成功時は以下を画面に表示する。

- タイトル
- 説明
- サムネイル
- 利用可能な動画フォーマット一覧
- 利用可能な音声フォーマット一覧
- 利用可能な字幕言語一覧
- 既定選択されたモードに応じた候補

### 8.5 失敗時の表示

失敗時は以下を表示する。

- エラーメッセージ
- 取得できた範囲の詳細情報
- 失敗理由が取得できる場合はその内容

### 8.6 プレイリスト対応

- 本アプリの対象は単一動画 URL を基本とする
- プレイリスト URL が入力された場合はエラーとし、未対応であることを表示する

## 9. ダウンロードモード仕様

### 9.1 共通方針

- 可能な限り動画と音声を最適な組み合わせで取得する
- 動画と音声が別フォーマットの場合は `ffmpeg` でマージする
- `ffmpeg` が存在しない場合は、マージが必要な候補を選べないようにするか、開始前にエラー表示する

### 9.2 最高画質モード

- 利用可能な動画候補のうち、最も高い画質を選択する
- 音声は常に利用可能な最高音質を選択する
- 映像と音声が別候補の場合はマージする
- 同等画質候補が複数ある場合の優先順位は次の通りとする
  1. 高い解像度
  2. 高い映像ビットレート
  3. より一般的なコンテナ

### 9.3 1080pモード

- 動画候補のうち、高さが `1080` 以下の候補が存在する場合、その中で最大の高さを持つものを選択する
- 高さが `1080` 以下の候補が存在しない場合、利用可能な動画候補のうち最小の高さを持つものを選択する
- 音声は常に利用可能な最高音質を選択する
- 映像と音声が別候補の場合はマージする

### 9.4 マニュアルモード

- ユーザーが動画画質と音質を個別に選択する
- 選択可能候補は、URL分析成功後に取得した一覧から生成する
- ユーザーが無効な組み合わせを選べないようにする
- 単体で成立する候補はそのままダウンロードする
- 組み合わせが必要な場合は `ffmpeg` でマージする
- マージ後のコンテナは `mp4` または `mkv` から選択可能とする
- 既定値は `mp4` とする

### 9.5 マニュアル候補の並び順

- 動画候補は解像度の高い順に並べる
- 音声候補は音質の高い順に並べる
- 各候補には最低限以下を表示する
  - フォーマットID
  - 解像度または音質
  - 拡張子
  - 映像専用 / 音声専用 / 統合済み の別

## 10. 字幕仕様

### 10.1 基本挙動

- 分析結果に字幕が存在する場合のみ、字幕チェックボックスを有効化する
- 字幕が存在しない場合はチェックボックスを無効化する
- チェックが ON の場合、選択された動画とあわせて字幕もダウンロードする
- 字幕埋め込みチェックボックスがオンのときはファイルに字幕を埋め込む
- 字幕チェックボックスがオフのときは別ファイルとしてダウンロードする

### 10.2 字幕言語の選択優先順位

字幕言語が複数ある場合、次の順で 1 つ選択する。

1. 日本語字幕
2. 英語字幕
3. 通常字幕のうち先頭候補
4. 自動生成字幕のうち先頭候補

### 10.3 字幕形式

- 取得可能な形式が複数ある場合は、`srt` を優先する
- `srt` がない場合は `vtt` を許容する

## 11. ファイル名仕様

### 11.1 初期値

- 初期ファイル名は動画タイトルをもとに生成する
- 初期値生成時はベース名を最大 32 文字までに切り詰める
- 拡張子は自動付与するため、入力欄には含めない

### 11.2 禁止文字の置換

Windows のファイル名として使用できない以下の文字は、自動的に `_` に置換する。

- `\\`
- `/`
- `:`
- `*`
- `?`
- `"`
- `<`
- `>`
- `|`

### 11.3 追加整形ルール

- 末尾の空白およびピリオドは削除する
- 制御文字は削除する
- 変換後に空文字になった場合は `video` を使用する
- Windows の予約名に一致する場合は末尾に `_` を付与する
  - 例: `CON`, `PRN`, `AUX`, `NUL`, `COM1` など
- オリジナルタイトルが空白文字またはユニコード系空白文字の場合は`video`という名前にする

## 12. ダウンロード先仕様

- ユーザーはダウンロード先ディレクトリを選択できる
- デフォルトボタン押下時は `%UserProfile%\Downloads` を設定する
- 直前に使用したダウンロード先は設定ファイルに保存する
- 次回起動時は保存済みダウンロード先を初期値として表示する
- 保存済みパスが存在しない場合は `%UserProfile%\Downloads` にフォールバックする

## 13. ダウンロード実行仕様

### 13.1 開始条件

`ダウンロード開始` ボタンは以下の条件を満たしたときのみ有効とする。

- URL分析が成功している
- ダウンロード先ディレクトリが有効である
- マニュアルモード時は必要な画質・音質が選択済みである
- `yt-dlp` が利用可能である
- マージが必要な場合は `ffmpeg` が利用可能である

### 13.2 実行中

- UI を完全にフリーズさせない
- プログレスバーで進捗を表示する
- 少なくとも以下を表示する
  - 全体進捗率
  - 現在ダウンロード速度
  - 推定残り時間
  - ダウンロード済みバイト数
  - 残りバイト数
  - 現在処理中ステップ
- 実行中は重複起動防止のため、主要操作を無効化する

### 13.3 中止

- 中止はダウンロード中のみ許可する
- URL分析中の中止は許可しない
- 中止時の状態は `失敗` ではなく `中止` として扱う
- 中止時は中間生成物、一時ファイル、未完成ファイルをクリーンアップする
- 中止完了後は再度 URL分析およびダウンロードを実行可能とする

### 13.4 完了時

- 完了メッセージを表示する
- 設定で有効な場合、出力先フォルダを自動で開く

### 13.5 失敗時

- エラーメッセージを表示する
- 詳細なエラー内容を表示する
- ログがある場合は参照可能にする

## 14. 既存ファイル衝突仕様

同名ファイルが出力先に既に存在する場合は、ダウンロード開始前に確認ダイアログを表示する。

選択肢は次の 2 つとする。

- 上書き
- キャンセル

既定値は `キャンセル` とする。

## 15. 設定保存仕様

### 15.1 保存対象

設定ファイルには少なくとも以下を保存する。

- 前回選択したダウンロードモード
- 前回選択した画質
- 前回選択した音質
- 前回選択した出力コンテナ
- 字幕ダウンロード ON/OFF
- 字幕埋め込みチェックボックス ON/OFF
- 前回指定したダウンロード先ディレクトリ
- 出力先フォルダを自動で開く ON/OFF
- ファイル名入力欄の直近値

### 15.2 保存タイミング

設定は次のタイミングで保存する。

- ユーザーが `設定保存` ボタンを押したとき
- アプリ終了時

### 15.3 起動時の挙動

- 設定ファイルが存在する場合は読み込む
- 読み込み成功時は UI に反映する
- 設定ファイルが壊れている場合は既定値で起動する
- 設定ファイルが壊れている場合は、既定値で上書きして修復する

## 16. エラー処理

少なくとも以下をエラーケースとして扱う。

- URL 未入力
- URL分析失敗
- 非対応 URL
- プレイリスト URL 入力
- `yt-dlp` 未検出
- `ffmpeg` 未検出
- ダウンロード先未指定
- ダウンロード先ディレクトリが存在しない
- フォーマット取得失敗
- ダウンロード失敗
- マージ失敗
- 字幕取得失敗
- 設定ファイル読み込み失敗
- 設定ファイル書き込み失敗
- ネットワーク接続失敗

エラーメッセージは、ユーザー向けの簡易表示と詳細表示を区別してよい。

## 17. ログ仕様

- エラー時に原因追跡できるログを残す
- ログは少なくとも日時、処理種別、対象 URL、エラー概要、詳細例外を含む
- ログ保存先はアプリ実行ディレクトリ配下の `logs` フォルダとする
- 1 実行単位または日付単位でログファイルを分けてよい

## 18. 非機能要件

- 長時間処理中でも UI 応答性を保つ
- 単一 URL の分析からダウンロード完了までを GUI 上で完結できる
- 設定ファイルが壊れても起動不能にならない
- 想定外エラー時にもアプリ全体が即終了しにくい構成とする
- 日本語 UI を基本とする
